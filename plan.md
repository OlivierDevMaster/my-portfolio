## Project Name

**Developer Portfolio & Tech Blog**

## Project Description

Create a modern personal portfolio and technology blog for a Full-Stack Engineer and Product Engineer. The website should showcase professional experience, technical expertise, projects, case studies, articles, and thoughts on software development, product building, AI, and system design.

The goal is to establish credibility, attract recruiters, clients, startups, and potential collaborators, while also serving as a platform to share technical knowledge and project insights.
